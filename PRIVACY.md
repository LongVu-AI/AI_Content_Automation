# Privacy Policy

AI Content Automation respects user privacy and complies with TikTok's data policies.

## Data Collection
- We collect only TikTok open_id and display_name for authentication.
- We store access tokens and refresh tokens securely in encrypted Notion database.
- We do not collect personal data beyond what is required for publishing.

## Data Usage
- Tokens are used only to publish videos on behalf of the authorized user.
- Data is not shared with third parties.
- Users can request data deletion at any time.
